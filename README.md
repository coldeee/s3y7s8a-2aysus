# Мой город

Симулятор мэра для детей 9–13 лет. За 7 игровых дней ребёнок решает, копить или тратить, и сам видит, как работают инвестиция, вклад и кредит.

ВШЭ × СберKids · трек B «Игры» · команда «Роскошный минимум»: Арсений Сушков, Виктория Пугач, Богдан Рыкованов, Алёна Полякова, Андрей Захаров.

**Играть:** https://coldeee.github.io/s3y7s8a-2aysus/

## Учебная цель

После игры ребёнок умеет сравнить цену и пользу траты, решить, копить или потратить, и проверить, хватит ли денег.

- **Инвестиция:** магазин стоит денег сейчас и приносит доход каждый день потом.
- **Вклад:** то, что не потратил, к вечеру подрастает на 5%.
- **Кредит:** ремонт сразу, а завтра вернуть больше (15 + 8).

## Как играть

7 дней, в каждом 2 улучшения.

1. **Утро.** Житель просит о помощи. Ребёнок решает, какое здание закроет просьбу.
2. **Город.** 5 зданий по 3 уровня. У каждого улучшения есть цена, польза и уход.
3. **Вечер.** Итог дня: что пришло, что ушло, сколько осталось в казне. Если просьбу не закрыли, игра показывает, какое здание помогло бы и почему.

День 3: фестиваль еды, вложиться или нет. День 5: буря, чинить своими, в кредит или не чинить.

В финале выходит газета про город: рейтинг против эталона, звание мэра, голоса жителей. Газету можно отправить другу одной кнопкой.

## Запуск

Сборки нет, это статика. Из папки игры:

```sh
python3 -m http.server 8000
```

Открыть `http://<IP ноутбука>:8000` в песочнице СберKids ([Android](https://github.com/vveidi/sber-hse-hackathon-2026-android), [iOS](https://github.com/vveidi/sber-hse-hackathon-2026-ios)). Эмулятор Android: `http://10.0.2.2:8000`. Можно открыть и `index.html` с диска.

## Устройство

```
index.html          разметка
css/                стили, @font-face
js/game.js          вся логика
data/content.json   наполнение: тексты, цены, жители, события
data/content.js     копия JSON для открытия с диска (file:// не даёт fetch)
fonts/ img/ audio/  локальные ресурсы
```

- Только HTML, CSS и JavaScript, без библиотек и фреймворков. Графика: SVG и DOM, звук: Web Audio.
- Внешних запросов нет, все ресурсы лежат рядом с игрой, пути относительные.
- Вес набора файлов около 2,5 МБ.
- Прогресс не сохраняется, состояние живёт в памяти страницы.
- Звук включается только после касания, есть переключатель.

## Канал с приложением

Все события идут через `window.postMessage({ type }, "*")`, новых событий нет.

| Событие | Когда |
|---|---|
| `COMPLETED_EVENT` | один раз: сделано улучшение и принято решение в бурю |
| `FINISH_EVENT` | партия закончилась, показана газета |
| `SHARING_EVENT` | «Поделиться»: текст и картинка газеты (data URL) |
| `VIBRATION_EVENT` | отклик на улучшение и шеринг |
| `CLOSE_EVENT` | выход из игры |

## Контент без релиза

Всё наполнение лежит в `data/content.json`. Файл подменяют на CDN, и игра меняется без правки кода и без релиза приложения:

- `cfg`: дни, стартовые монеты, налоги, % вклада, доплата по кредиту, пороги, веса рейтинга, эталон;
- `buildings`: названия, цены по уровням, эффекты, подсказка «а если не улучшать»;
- `residents`: жители по дням, их просьбы и `target`, то есть здание, которое закрывает просьбу;
- `events`: события, их дни, варианты и эффекты;
- `cities`, `news`, `ui`: названия городов, заголовки газеты, все тексты.

После правки JSON обновить `data/content.js`. Если файл пустой или битый, игра показывает понятный экран и не падает.
